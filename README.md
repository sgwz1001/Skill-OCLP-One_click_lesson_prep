# 一键备课（one-click-lesson-prep）

> 一个 WorkBuddy / CodeBuddy Skill：教师只提供教材信息或粘贴课文原文，
> 即可自动走完「六步备课法」，产出单元分析、教学目标、课堂任务链、衔接语与评价语、分层作业与板书，
> 以及即梦 AI 课件图片提示词，并按统一命名规范自动落盘成文件。

## 这是什么

当你提到「备课 / 教案 / 教师 / 上课 / 课件 / 单元设计 / 课文教学」，或上传教材照片、粘贴课文原文时触发。
核心理念：**教师只管提供信息，备课的讲究、步骤、产出由技能一步步做完。**

## 两种输入模式

- **模式 A · 教材定位**：你告诉我【教材版本】【年级】【册次】【单元名称】【课文篇目】（可选教龄/学情/课件张数）。
- **模式 B · 原文输入**：直接粘贴课文原文即可，无需出版社信息。

信息不全时不要反复追问——能推断就推断，推断不了再用一句话补齐。

## 六步备课法（自动执行）

1. **单元整体分析**（课标 + 教材 + 学情 + 重难点）
2. **定教学目标**（具体、可观察、可检测；语言/思维/文化三维）
3. **设大问题 + 任务活动**（大问题统摄全课，任务链层层递进）
4. **衔接语 + 分层评价语**（基础/提升/拓展三层）
5. **分层作业 + 板书**（基础/提升/拓展三层作业，主副板书分区）
6. **生成即梦 AI 图片提示词**（5–8 张 16:9 课件页，含主题/视觉/排版/风格）

## 产出物（自动命名落盘）

| 产出物 | 文件类型（--type） | 扩展名 |
|---|---|---|
| 单元整体分析 | 单元分析 | md |
| 完整教案 | 教案 | md / docx |
| 即梦 AI 课件图片提示词清单 | 课件图片提示词 | md |
| （可选）课件 HTML 原型 | 课件 | html |

命名遵循「文件名-文件类型-时间-v版本号&备注」规范（见 `文件重命名规范` skill），主题拼接规则：
`{教材版本或"课文"}{学科}{年级}{册次}{单元/课文名}`。

## 如何安装

把本文件夹整体复制到你的 skill 目录：

- 用户级：`C:\Users\<你的用户名>\.workbuddy\skills\`
- 项目级：`<你的工作目录>\.workbuddy\skills\`

## 文件结构

```
one-click-lesson-prep/
├── SKILL.md                  # 六步备课提示词、输入模式、命名落盘逻辑
├── references/
│   └── examples.md           # 命名示例
└── scripts/
    └── suggest_name.py       # 规范命名计算脚本（同 文件重命名规范）
```
